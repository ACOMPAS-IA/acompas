# ACO-032 — Flujo E2E

Sprint 1

## Objetivo

Integrar las piezas del Sprint 1 en el flujo extremo a extremo de la demo interna.

## Incluye / debe quedar hecho

- Login → acceso autorizado → carga de documento sintético → anonimización → conversación → respuesta.

- Contratos entre frontend, API, anonimización y conversación integrados.

- Flujo ejecutable localmente.

## Fuera de alcance

- No incorpora funcionalidades de producción ni datos reales.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
