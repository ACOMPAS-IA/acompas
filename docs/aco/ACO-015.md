# ACO-015 — Whitelist piloto

Sprint 1

## Objetivo

Implementar el control de acceso del piloto mediante una whitelist de usuarios autorizados, compatible con el modelo de identidad definido para ACOMPAS.

## Incluye / debe quedar hecho

- Usuario autorizado puede acceder.

- Usuario no autorizado es rechazado.

- No se almacena en ACOMPAS la correspondencia email↔UUID; Keycloak es el custodio de esa relación.

## Fuera de alcance

- No sustituye Keycloak ni implementa gestión completa de usuarios.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
