# ACO-024 — API anonimización

Sprint 1

## Objetivo

Exponer el servicio de anonimización mediante una interfaz HTTP interna del backend.

## Incluye / debe quedar hecho

- Endpoint definido y documentado.

- Entrada de texto y salida anonimizada conforme al contrato de 020.

- Errores y validaciones básicas.

- No devuelve el texto original en la respuesta.

## Fuera de alcance

- No añade persistencia del original (025).

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
