# ACO-028 — Seguridad de API key

Sprint 1

## Objetivo

Proteger la API key del proveedor LLM y evitar su exposición en frontend, repositorio o logs.

## Incluye / debe quedar hecho

- La clave se obtiene mediante configuración segura del backend.

- No aparece en código fuente ni respuestas HTTP.

- No se expone al navegador.

- Pruebas/revisión de ausencia de exposición evidente.

## Fuera de alcance

- No implementa el Gateway completo (027).

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
