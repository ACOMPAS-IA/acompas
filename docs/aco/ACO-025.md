# ACO-025 — No persistencia del original

Sprint 1

## Objetivo

Garantizar que el documento original no se persiste en el flujo de anonimización.

## Incluye / debe quedar hecho

- El original no se escribe en base de datos ni almacenamiento persistente.

- No se registran originales en logs.

- La interfaz devuelve únicamente la información necesaria para continuar el flujo.

- Pruebas verificables de ausencia de persistencia.

## Fuera de alcance

- El right-to-forget y audit log completos están fuera de Sprint 1.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
