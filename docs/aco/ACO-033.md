# ACO-033 — Tests E2E

Sprint 1

## Objetivo

Automatizar pruebas del flujo extremo a extremo definido en 032.

## Incluye / debe quedar hecho

- Caso feliz E2E.

- Caso de usuario no autorizado.

- Caso de documento que no supera validación, si el flujo lo contempla.

- CI ejecuta las pruebas o deja documentada la dependencia técnica necesaria.

## Fuera de alcance

- No sustituye las pruebas unitarias específicas de 026.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
