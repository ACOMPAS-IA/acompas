# ACO-014 — Validación JWT

Sprint 1

## Objetivo

Integrar la validación de JWT en el backend para proteger los endpoints que lo requieran.

## Incluye / debe quedar hecho

- El backend rechaza tokens ausentes o inválidos.

- Un JWT válido permite acceder al endpoint protegido.

- Pruebas del comportamiento de autorización.

## Fuera de alcance

- No redefine Keycloak/OIDC; usa la configuración de 013.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
