# ACO-023 — Umbral de confianza

Sprint 1

## Objetivo

Aplicar el umbral de confianza y las reglas/filtros de política para decidir qué hallazgos se anonimizan.

## Incluye / debe quedar hecho

- Umbral configurable/documentado.

- Filtros para falsos positivos previstos.

- Separación entre entidades detectadas y entidades que se anonimizan.

- No pasan documentos al flujo posterior si no cumplen la validación prevista.

## Fuera de alcance

- No expone API HTTP (024).

- No cubre persistencia ni derecho al olvido completo.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
