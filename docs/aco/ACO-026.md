# ACO-026 — Tests anonimización

Sprint 1

## Objetivo

Construir la batería de pruebas del pipeline de anonimización de Sprint 1.

## Incluye / debe quedar hecho

- Tests de detección.

- Tests de anonimización.

- Tests de umbral/falsos positivos relevantes.

- Tests de API y no persistencia.

- Ejecución correcta en CI.

## Fuera de alcance

- No incluye L2/L3 de anonimización ni cobertura de producción.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
