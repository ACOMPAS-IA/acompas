# ACO-018 — Login

Sprint 1

## Objetivo

Implementar el login del frontend mediante el mecanismo de identidad definido en Keycloak.

## Incluye / debe quedar hecho

- Usuario puede iniciar sesión mediante el flujo configurado.

- La aplicación obtiene y gestiona el resultado de autenticación de forma compatible con el backend.

- Errores básicos de autenticación tratados.

- Criterio móvil sobre el marco de ACO-017: a 360 px de ancho no hay scroll horizontal; el formulario y sus acciones son utilizables sin zoom y los errores se leen sin romper el layout. En escritorio el formulario se mantiene centrado. `AuthShell` no incluye cabecera, navegación, pie ni disclaimer. La comprobación del layout es manual; los tests automáticos cubren estructura, estados y llamadas.

## Fuera de alcance

- No implementa el cliente general de API (019).

- No modifica el layout ni `AuthShell`: los aporta ACO-017.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance. Además, que el login cumple el criterio móvil a 360 px sin romper el layout.
