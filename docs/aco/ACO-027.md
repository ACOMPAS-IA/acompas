# ACO-027 — LLM Gateway v0 / encaje

Sprint 1

Estado: criterios de aceptación pendientes de revisión por Miguel y Luis.

## Objetivo

Fijar el encaje mínimo del LLM Gateway necesario para permitir el flujo conversacional del Sprint 1.

## Incluye / debe quedar hecho

- Contrato mínimo entre conversación y proveedor LLM definido.

- Integración mínima funcional con Claude prevista para la demo.

- Gestión de configuración/secreto compatible con 028.

- Encaje arquitectónico revisado por Miguel.

## Fuera de alcance

- No convertirlo en una plataforma completa de gateway.

- RAG completo queda fuera de Sprint 1.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
