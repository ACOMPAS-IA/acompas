# ACO-012 — Realm/configuración

Sprint 1

## Objetivo

Crear y configurar el realm de ACOMPAS sobre Keycloak.

## Incluye / debe quedar hecho

- Realm de ACOMPAS creado y reproducible.

- Configuración base preparada para clientes y usuarios del piloto.

- Documentación de la configuración relevante.

## Fuera de alcance

- No implementa todavía el flujo OAuth2/OIDC de la aplicación (013).

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
