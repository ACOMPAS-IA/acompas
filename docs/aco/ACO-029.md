# ACO-029 — System prompt v0

Sprint 1

Estado: criterios de aceptación pendientes de revisión por Miguel y Luis.

## Objetivo

Definir el system prompt inicial que gobierna el comportamiento conversacional de ACOMPAS en Sprint 1.

## Incluye / debe quedar hecho

- Prompt versionado.

- Define alcance: comprensión, no diagnóstico ni sustitución del médico.

- Incorpora restricciones de seguridad relevantes y control inicial de prompt injection.

- Preparado para conversación sobre documento.

## Fuera de alcance

- No implementa por sí solo el flujo conversacional completo (030).

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
