# ACO-013 — OAuth2/OIDC

Sprint 1

## Objetivo

Configurar el mecanismo de autenticación OAuth2/OIDC sobre Keycloak para ACOMPAS.

## Incluye / debe quedar hecho

- Cliente/protocolo configurado para el flujo previsto.

- Login/autenticación verificable localmente.

- Configuración documentada para integración posterior.

## Fuera de alcance

- No cubre la validación de JWT del API (014) ni la whitelist del piloto (015).

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
