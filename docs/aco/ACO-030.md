# ACO-030 — Conversación sobre documento

Sprint 1

Estado: criterios de aceptación pendientes de revisión por Miguel y Luis.

## Objetivo

Implementar el flujo conversacional mínimo en el que el usuario consulta sobre un documento clínico sintético previamente procesado.

## Incluye / debe quedar hecho

- Usuario puede formular una consulta sobre el documento.

- El contexto documental llega al LLM de forma controlada.

- Respuesta de Claude visible en la interfaz prevista.

- No se usan documentos reales.

## Fuera de alcance

- No incluye disclaimer final independiente (031).

- No incluye RAG completo.

## Criterio de revisión

La persona revisora debe comprobar que el código implementa el objetivo de esta ficha, que las dependencias indicadas están respetadas, que existen pruebas cuando el comportamiento es verificable y que no se introducen datos reales, persistencia o secretos fuera del alcance.
